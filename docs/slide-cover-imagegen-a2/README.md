# Cover silabus Imagegen A1–A2

161 pasangan cover dan tujuan untuk 23 bahasa dibuat memakai Imagegen bawaan dan diperiksa secara visual: karakter sederhana mengikuti Jerman/Polandia, latar tajam tanpa blur/bokeh. Satu pasangan per sublevel dipakai oleh 16 sesi; judul dan tujuan tetap berasal dari materi sesi masing-masing.

Seluruh target lengkap, termasuk Bulgaria A2.1, empat sublevel Islandia, dan seluruh A1–A2 Ukraina yang sebelumnya menunggu kuota. Materi A2 Ibrani, Persia, Jawa, Sunda, dan BIPA sudah tersedia di main terbaru dan memakai gambar A2 yang disiapkan sebelumnya.

Manifest memuat prompt asli, prompt perbaikan jika ada, dan status pemeriksaan setiap pasangan. Gambar produksi berada di `public/slide-cover/*-imagegen-v3.jpg` (1600 × 900).

Validasi: build produksi kedua aplikasi, pemeriksaan 322 JPEG dan kesamaan aset kedua repo, serta pemetaan 2.576 sesi pada 161 dek.
