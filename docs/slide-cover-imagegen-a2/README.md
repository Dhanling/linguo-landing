# Cover silabus Imagegen A1–A2

149 pasangan cover dan tujuan dibuat memakai Imagegen bawaan dan diperiksa secara visual: karakter sederhana mengikuti Jerman/Polandia, latar tajam tanpa blur/bokeh. Satu pasangan per sublevel dipakai oleh 16 sesi; judul dan tujuan tetap berasal dari materi sesi masing-masing.

Target: 161 sublevel pada 23 bahasa. Dua belas pasangan tertunda karena kuota Imagegen, tercantum pada `pending` di manifest. Sublevel tersebut sementara memakai aset sebelumnya; tidak diarahkan ke gambar yang belum tersedia.

Untuk Ibrani, Persia, Jawa, Sunda, dan BIPA, materi A2 belum tersedia di sumber. Aset A2 telah disiapkan, tetapi perubahan ini tidak membuat atau mengubah isi silabus.

Manifest memuat prompt asli, prompt perbaikan jika ada, dan status pemeriksaan setiap pasangan. Gambar produksi berada di `public/slide-cover/*-imagegen-v3.jpg` (1600 × 900).

Validasi: build produksi kedua aplikasi, pemeriksaan 298 JPEG dan kesamaan aset kedua repo, pemetaan 2.384 sesi, serta 129 dek yang tersedia.
