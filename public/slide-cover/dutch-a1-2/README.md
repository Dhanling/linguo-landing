# Cover Belanda A1.2 — Lingling

Dibuat melalui OpenAI Image API dengan model `gpt-image-2` menggunakan CLI imagegen bawaan Codex. Referensi gaya dan mascot: Belanda A1.1 dan Lingling dari pengguna.

- 16 sesi, masing-masing dua ilustrasi unik: `sesi-N-sampul-v1.jpg` dan `sesi-N-tujuan-v1.jpg`.
- Slide 1: ruang judul di atas, adegan sesuai topik di bawah.
- Slide 2: ruang teks di kiri, manusia bersama Lingling di kanan.
- Slide 3 dan seterusnya: latar bersama `/slide-cover/dutch-a1-1/latar-v1.jpg`.
- Format akhir JPEG 1600×900. Prompt dan parameter API: `prompts.json`.

Berkas disalin identik ke dashboard dan landing agar cover materi yang disimpan pengajar tetap terbaca di akun siswa.
